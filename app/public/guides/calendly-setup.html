Set up Calendly in 5 moves.

Get a booking link parents can use. Then paste your API token in the tutor dashboard so sessions land automatically.

  1. Create a free Calendly account with your school email.
  2. Make one event type: 30 or 60 minutes. Name it clearly, like ACT Math Session.
  3. Copy your public booking link from Share.
  4. Open Integrations → API and Webhooks. Create a Personal Access Token.
  5. Back in MindCraft Tutor Dashboard, open Calendly and paste the token. Connect.

Keep one personal Google Meet room as backup. Calendly handles booking. Meet handles the call if a session has no link yet.
