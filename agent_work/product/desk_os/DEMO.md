# Desk · fluid hub (sketch)

1. `cd agent_work/product/desk_os && python3 -m http.server 5180` → http://localhost:5180
2. Center: **help with?** + mascot. Under it: floating circular orbs (Record, Drop, Mail, Calendar, Binder, Google soon).
3. Click an orb → mascot fades, orb row becomes that tool’s soft sheet. Close returns to the hub.
4. Work floats quietly below as soft pills. Live transcript squeezes into a bottom capsule.
5. Type in help with? (mail / calendar / notes / drop / record) and hit Enter.
6. Local only. Google orb is gated.
